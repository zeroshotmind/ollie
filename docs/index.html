Install

two commands and three toggles
1One line in a terminal
bash <(curl -fsSL zeroshotmind.github.io/ollie/install.sh) click to copy

Or grab the DMG and right-click → Open. Either way it builds Ollie on your Mac — that's what lets macOS grant permissions to Ollie by name instead of refusing an unnotarized download. You'll want Ollama with qwen2.5:3b-instruct pulled; the installer walks you through it.

2Flip three toggles

macOS guards each capability, and each one fails silently — this is the step people miss. System Settings → Privacy & Security.

Input MonitoringHear the push-to-talk key. Missing → holding it does nothing.
AccessibilityPaste your words into the terminal. Missing → speech transcribes, nothing appears.
MicrophoneRecord while the key is held. Missing → your recordings are pure silence.

Ollie asks for all three on first launch and appears in each list on its own — flip the switches, don't use the + button.

3Quit and reopen it once

The key listener only picks up new permissions at startup. Then run.sh --doctor tells you whether all three actually took.

Honest about what it is

Weekend software, in the open. Phase 1 speaks Claude Code on Apple Silicon and nothing else. Phase 2 is a Codex CLI reader; Phase 3 diffs any terminal through the Accessibility API. If it breaks, the log is at ~/.ollie/ollie.log.
