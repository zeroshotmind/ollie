Install

One line, in a terminal:

bash <(curl -fsSL https://zeroshotmind.github.io/ollie/install.sh)

Or download the DMG above and right-click → Open “Install Ollie.command”. Either way the installer builds Ollie on your Mac — that's what lets macOS grant permissions to Ollie by name instead of blocking an unnotarized download. It fetches the source, sets up an isolated Python env with uv, and compiles the app bundle. You'll want Ollama with qwen2.5:3b-instruct pulled — the installer walks you through it.

What it does

🗣 Push-to-talk input

Hold right Option, speak, release — Whisper (MLX) types your words at the cursor of your terminal.

🔊 Narrated output

A local LLM decides what's genuinely new and worth saying, and says it — brief, loss-less, or verbatim, in four tones.

🤖 Autopilot

Give it a goal and it keeps prompting your agent until the goal is done — fenced by turn caps, focus checks and stall detection.

🎙 Two voices

Instant macOS say, or the Kokoro neural voice running ~50× real-time on the Neural Engine.

🔒 Local by construction

Whisper, Qwen and Kokoro all run on-device. The built-in settings report shows every model and API — no cloud anywhere.

🫧 Stays out of the way

No dock icon, no menu bar. A draggable orb that never steals focus; right-click it for everything.

After installing: three toggles

macOS guards each capability behind a permission, and each fails silently — so this is the one manual step. System Settings → Privacy & Security:

PermissionWhy Ollie needs it
Input Monitoringhear the push-to-talk key
Accessibilitytype your transcribed speech into the terminal
Microphonerecord while the key is held

Ollie requests all three at first launch and appears in each list by itself — flip the toggles, then quit and reopen it once. ~/.ollie/src/run.sh --doctor verifies everything.
